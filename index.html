資料收集範圍

本App僅會在您的裝置本地端建立檔案名稱與副檔名索引，用於提供快速檔案搜尋功能。本App不會收集您的姓名、電子郵件、電話號碼、聯絡人、位置資訊或其他可識別個人的資料。

檔案存取用途

本App會透過iOS系統提供的檔案選擇器，請您主動授權特定資料夾。資料夾存取權限僅用於讀取該資料夾內的檔案名稱與副檔名，以建立搜尋索引。本App不會在未經您授權的情況下存取其他資料夾或檔案。

資料儲存與使用

所有索引資料與搜尋設定皆儲存在您的裝置本地端。本App不會將您的檔案名稱、檔案路徑、搜尋紀錄或索引資料上傳至伺服器。

資料不外流保證

本App及開發者不會、也無法將您的檔案內容、檔案名稱、索引資料或搜尋紀錄上傳、分享、出售或提供給第三方。

雲端硬碟資料

若您透過 iCloud Drive、Google Drive、OneDrive 或其他雲端硬碟授權資料夾，本App僅透過iOS系統檔案權限讀取您選定資料夾中的檔案名稱與副檔名。雲端檔案的帳號登入、同步與權限管理皆由 iOS「檔案」App與各雲端服務提供者處理。

訂閱與付款

若您使用 App 內訂閱功能，付款與訂閱管理皆由Apple App Store處理。本App不會取得或儲存您的信用卡資料、付款帳號或完整交易資訊。

資料刪除

您可以刪除本App以移除儲存在本機的索引資料與設定。

政策更新

本隱私權政策可能因App功能調整或法規要求而更新。更新後的版本將發布於本頁面。

聯絡方式

若您對本隱私權政策有任何問題，可透過App Store頁面提供的開發者聯絡資訊與我們聯繫。

资料收集范围

本App仅会在您的设备本地端建立文件名称与扩展名索引，用于提供快速文件搜索功能。本App不会收集您的姓名、电子邮件、电话号码、联系人、位置信息或其他可识别个人的资料。

文件访问用途

本App会通过iOS系统提供的文件选择器，请您主动授权特定文件夹。文件夹访问权限仅用于读取该文件夹内的文件名称与扩展名，以建立搜索索引。本App不会在未经您授权的情况下访问其他文件夹或文件。

资料存储与使用

所有索引资料与搜索设置皆存储在您的设备本地端。本App不会将您的文件名称、文件路径、搜索记录或索引资料上传至服务器。

资料不外流保证

本App及开发者不会、也无法将您的文件内容、文件名称、索引资料或搜索记录上传、分享、出售或提供给第三方。

云端硬盘资料

若您通过 iCloud Drive、Google Drive、OneDrive 或其他云端硬盘授权文件夹，本App仅通过iOS系统文件权限读取您选定文件夹中的文件名称与扩展名。云端文件的账号登录、同步与权限管理皆由 iOS“文件”App与各云端服务提供者处理。

订阅与付款

若您使用 App 内订阅功能，付款与订阅管理皆由Apple App Store处理。本App不会取得或存储您的信用卡资料、付款账号或完整交易信息。

资料删除

您可以删除本App以移除存储在本机的索引资料与设置。

政策更新

本隐私权政策可能因App功能调整或法规要求而更新。更新后的版本将发布于本页面。

联系方式

若您对本隐私权政策有任何问题，可通过App Store页面提供的开发者联系信息与我们联系。

Privacy Policy

Last updated: May 1, 2026

Scope of Data Collection

This App only creates an index of file names and file extensions locally on your device to provide fast file search functionality. This App does not collect your name, email address, phone number, contacts, location information, or other personally identifiable information.

Purpose of File Access

This App uses the file picker provided by the iOS system to let you actively authorize specific folders. Folder access permission is used only to read file names and file extensions within the selected folders in order to build a search index. This App does not access any other folders or files without your authorization.

Data Storage and Use

All index data and search settings are stored locally on your device. This App does not upload your file names, file paths, search history, or index data to any server.

No Data Disclosure

This App and its developer do not and cannot upload, share, sell, or provide your file contents, file names, index data, or search history to any third party.

Cloud Drive Data

If you authorize folders through iCloud Drive, Google Drive, OneDrive, or other cloud drives, this App only reads the file names and file extensions in the folders you selected through iOS system file permissions. Account sign-in, synchronization, and permission management for cloud files are handled by the iOS Files app and the respective cloud service providers.

Subscriptions and Payments

If you use the in-app subscription feature, payment and subscription management are handled by the Apple App Store. This App does not obtain or store your credit card information, payment account, or complete transaction information.

Data Deletion

You can delete this App to remove locally stored index data and settings.

Policy Updates

This Privacy Policy may be updated due to app changes or legal requirements. Updated versions will be posted on this page.

Contact

If you have any questions about this Privacy Policy, you may contact us through the developer contact information provided on the App Store page.

プライバシーポリシー

最終更新日：2026年5月1日

収集するデータの範囲

本Appは、高速なファイル検索機能を提供するため、端末内でファイル名と拡張子の索引のみを作成します。本Appは、氏名、メールアドレス、電話番号、連絡先、位置情報、その他個人を識別できる情報を収集しません。

ファイルアクセスの目的

本Appは、iOSシステムが提供するファイルピッカーを通じて、ユーザーが特定のフォルダを明示的に許可できるようにします。フォルダへのアクセス権限は、検索索引を作成するために、選択されたフォルダ内のファイル名と拡張子を読み取る目的のみに使用されます。本Appは、ユーザーの許可なく他のフォルダやファイルにアクセスしません。

データの保存と利用

すべての索引データと検索設定は、ユーザーの端末内に保存されます。本Appは、ファイル名、ファイルパス、検索履歴、索引データをサーバーへアップロードしません。

データを外部提供しないこと

本Appおよび開発者は、ファイル内容、ファイル名、索引データ、検索履歴を第三者へアップロード、共有、販売、提供することはなく、またそれを行うこともできません。

クラウドドライブのデータ

iCloud Drive、Google Drive、OneDrive、その他のクラウドドライブ内のフォルダを許可した場合でも、本AppはiOSシステムのファイル権限を通じて、選択されたフォルダ内のファイル名と拡張子のみを読み取ります。クラウドファイルのアカウントログイン、同期、権限管理は、iOSの「ファイル」Appおよび各クラウドサービス提供者によって処理されます。

サブスクリプションと支払い

App内サブスクリプション機能を利用する場合、支払いとサブスクリプション管理はApple App Storeによって処理されます。本Appは、クレジットカード情報、支払いアカウント、完全な取引情報を取得または保存しません。

データの削除

本Appを削除することで、端末内に保存された索引データと設定を削除できます。

ポリシーの更新

本プライバシーポリシーは、App機能の変更または法令上の要件により更新される場合があります。更新後の版は本ページに掲載されます。

お問い合わせ

本プライバシーポリシーについてご質問がある場合は、App Storeページに記載されている開発者連絡先情報からお問い合わせください。
